Với media thật, Chrome không còn che IP host bằng mDNS (xxx.local) nên host candidate có thể lộ IP LAN thật: hãy che thông tin này trước khi chia sẻ ảnh chụp/log. Với media giả lập (chưa cấp quyền), Chrome che IP bằng mDNS, đó là bình thường. Gọi loopback cùng máy cho metric gần hoàn hảo; muốn thấy suy giảm hãy dùng Chrome DevTools > Network throttling, clumsy (Windows) hoặc tc netem (Linux).
